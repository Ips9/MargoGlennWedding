FAQ

Veelgestelde vragen

Wanneer moet ik RSVP'en?

De definitieve RSVP-deadline kan hier automatisch vanuit wedding settings verschijnen.

Kan ik mijn antwoord later wijzigen?

Ja. De persoonlijke uitnodiging kan opnieuw geopend worden zolang wijzigen nog is toegestaan.

Zijn kinderen welkom?

Nee. We vieren onze dag graag zonder kinderen.

Wat bij een allergie of dieet?

Geef dit tijdens de RSVP door. We houden er in de mate van het mogelijke rekening mee.

Waar kan ik parkeren?

De definitieve parkeerinstructies kunnen hier later helder worden toegevoegd.

Kan ik foto's ontvangen na het feest?

Via de RSVP kan een e-mailadres worden achtergelaten. Dat adres gaat uitsluitend naar Margo & Glenn.

Kan ik een liedje aanvragen?

Ja — via de muzieksectie hierboven. Iedereen mag minstens één dansvloerkandidaat indienen.

Mag ik foto's delen?

Ja. Deze preview bevat alvast een fotohoek die later naar echte gedeelde opslag kan worden gekoppeld.
